## 1. Resolved Baseline Architectural Decisions
The following baseline decisions are established directly from the approved PRD, TRD, and Build Guide:

1. **Development & IDE Environment:** Google Antigravity IDE is the agentic development environment, not the production backend.
2. **Backend & Database:** Supabase (Auth, Postgres with strict RLS, Private Storage, Edge Functions, Realtime).
3. **Frontend Stack:** React + TypeScript + Vite + Tailwind CSS design system with mobile-first layout (bottom navigation for mobile, responsive layout for desktop).
4. **Security Boundary:** Supabase Row Level Security (RLS) is the non-negotiable security boundary. Frontend filtering is never relied upon for data isolation. Service-role keys are strictly forbidden in client-side code.
5. **Deterministic Metrics vs AI:** All financial and operational metrics are computed deterministically in SQL / database functions. The AI (Munim Ji) only explains metrics and generates verdicts; it is strictly prohibited from performing financial arithmetic.
6. **New vs Existing Business Fork:**
   - **New Business:** Full Day 1 baseline (initial investment, owner capital, setup/equipment costs, working capital, monthly fixed expenses, target recovery period).
   - **Existing Business:** Streamlined 5–6 question Business Snapshot (approx age, self-reported profitability, monthly revenue/expense ranges, whether initial investment is already recovered, key operational pain points).
   - **Suppression:** If investment is already recovered, investment recovery progress UI and formulas are suppressed.
7. **AI Learning / Calibration Period:** AI verdict engine stays in `learning` state until sufficient data accumulation threshold is satisfied (~2–4 weeks / 7–14 reports).
8. **Language & Formatting:** Full English and Hindi bilingual UI toggle (via i18next). Numbers and currency symbols are never translated or modified phonetically.
9. **Watermarked PDF Export:** All exported reports must embed a permanent, server-rendered `"Generated by Munim Ji – Confidential"` watermark.
10. **Strict Scope Exclusions:** No POS billing, no barcode scanner, no SKU-level inventory, no generic accounting replacement.
11. **One Chart Rule:** Exactly one vertical bar chart on the dashboard with a 3-mode switch (Revenue & Profit Trend / Profit by Business / Capital Allocation).
12. **Notification Bell:** In-app notification bell opens as a slide-down modal popup, never as a separate page.
13. **Every Button & Card Must Work:** Zero decorative dead UI anywhere in the app.
